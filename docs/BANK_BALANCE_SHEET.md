# Банковский баланс и сверка платёжеспособности

## Назначение

Банк хранит пулы ликвидности, процентные резервы, кредитный портфель, вклады и требования по невыплаченным процентам в разрезе нации и валюты. Эти суммы нельзя складывать между разными валютами без явной конвертации по курсу.

RaskolVault формирует производную сверку по каждой паре `nation + currency`. Она нужна, чтобы обнаруживать отрицательный собственный капитал и показывать, из каких частей состоят активы и обязательства.

## Признанные активы

Для одной валюты:

```
cash_assets = liquidity_pool + interest_reserve
loan_receivables = outstanding_loan_principal + accrued_loan_interest
total_assets = cash_assets + loan_receivables
```

В кредитный портфель входят как обычные активные кредиты, так и долги в статусе `RECOVERY`. Для активного кредита проценты проецируются до текущего времени, но только до договорной даты погашения. У долга в процедуре взыскания проценты заморожены.

## Обязательства

```
deposit_liabilities = active_deposit_principal + projected_deposit_interest
total_liabilities = deposit_liabilities + unpaid_interest_claims
```

Проценты активных вкладов рассчитываются для сверки без изменения объекта и без преждевременной записи в SQLite. Требования из `bank_interest_payables` учитываются отдельно: это проценты, признанные к выплате после закрытия вклада, но ещё не выплаченные полностью.

## Собственный капитал

```
equity = total_assets - total_liabilities
```

- Положительное значение означает, что признанные активы превышают обязательства.
- Нулевое значение означает отсутствие запаса собственного капитала.
- Отрицательное значение означает дефицит признанных активов относительно обязательств и отмечается аудитом как FAIL.

Это диагностическая оценка платёжеспособности, а не утверждение, что все активы немедленно ликвидны. Кредитные требования могут быть неликвидными, даже если собственный капитал положительный.

## Залоговые активы

Залоговые лоты со статусами `PLEDGED` и `HELD` не прибавляются к денежным активам и не уменьшают обязательства заёмщика автоматически.

Для лотов `HELD` оценочная стоимость выводится отдельно как справочная величина. В баланс активов она не входит. Денежное поступление признаётся только после подтверждения фактической реализации лота; затем фактическая выручка направляется на проценты, основной долг и, при наличии, surplus заёмщику.

## Административная диагностика

- `/rv bank admin stats <нация>` — сводка по лимиту кредитования и балансам каждой валюты.
- `/rv admin selftest` — проверка банковской платёжеспособности по каждой валюте вместе с остальными экономическими инвариантами.

В выводе для каждой валюты отображаются ликвидность, кредитные требования, обязательства, активы, собственный капитал и справочная оценка удерживаемого залога.

## Границы модели

Сверка агрегирует текущее состояние банковских сущностей из SQLite snapshot. Она не является полноценной double-entry general ledger: у банка пока нет отдельного набора дебетовых и кредитовых проводок для каждого внутреннего счёта. Поэтому сверка выявляет дефицит активов относительно признанных обязательств, но не заменяет будущий журнал двойной записи и сверку каждой операции по бухгалтерским счетам.

Все суммы сравниваются только внутри одной валюты. Общий итог по разным валютам намеренно не рассчитывается: для него потребовались бы единая отчётная валюта, зафиксированный курс оценки и политика переоценки.
