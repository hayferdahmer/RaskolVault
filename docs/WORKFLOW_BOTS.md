# Workflow-боты RaskolVault

Все проверки выполняются в GitHub Actions. Они не имеют доступа к игровому серверу и не меняют игровые данные.

## Установленные боты

### Economy Guardian

Запускает полный Maven verify на Java 25 для финансовых изменений. Для изменений в API, кошельках, SQLite, банке, аукционе, обмене и резервах требует хотя бы один изменённый тестовый файл.

### SQL Migration Sentinel

Проверяет SQLite-тесты, банковские таблицы и маркер импорта YAML. Его задача — ловить регрессии схемы и повторного запуска миграции.

### CodeQL Security Bot

Запускает статический анализ Java на push, pull request и по еженедельному расписанию. Находит потенциальные уязвимости в потоках выполнения, обработке входных данных и использовании API.

### Dependency Guardian

Анализирует изменения зависимостей в pull request и блокирует изменения с уязвимостями уровня Moderate и выше.

### Release Gatekeeper

Сверяет контракт сборки и метаданные релиза: Java 25, стабильный Paper API 26.2, api-version 26.2 и одинаковую версию в pom.xml и plugin.yml.

## Следующие кандидаты

- **Raskol API Contract Bot** — проверка совместимости RaskolVault ↔ RaskolCore ↔ RaskolClasses по публичным интерфейсам.
- **Economy Invariant Bot** — отдельные сценарии конкурентных переводов, двойных списаний, лимитов эмиссии, escrow и сверки резервов.
- **Thread Safety Bot** — анализ Bukkit API-вызовов из async-задач и запрет небезопасного доступа к Player/Inventory/World.
- **Backup Restore Drill Bot** — периодическое восстановление SQLite-копии во временную БД и проверка целостности.
- **Release Artifact Auditor** — проверка состава JAR, отсутствия SNAPSHOT-артефактов и совпадения версии/контрольной суммы.

## Принцип

Бот не должен автоматически сливать финансовые изменения в main. Его задача — дать проверяемый результат и заблокировать небезопасный pull request. Решение о слиянии остаётся за владельцем проекта.
